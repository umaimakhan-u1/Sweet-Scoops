# 🍦 Cream & Co. — Premium Ice Cream Website

Cream & Co. is a modern, responsive, and interactive ice cream shop website designed to provide a smooth, attractive, and engaging user experience.

The website presents handcrafted ice cream flavors, special offers, customer reviews, an image gallery, contact information, and a functional shopping cart with an order completion system.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Attractive hero section
- Call-to-action buttons
- Ice cream flavor menu
- Product cards with images and prices
- Flavor categories
- Interactive shopping cart
- Add products to cart
- Increase and decrease product quantities
- Remove products from cart
- Automatic total price calculation
- Complete Order form
- Order confirmation message
- Special offers section
- Image gallery
- Customer reviews
- Contact form
- Mobile navigation menu
- Smooth section-based navigation

## 🛒 Shopping Cart

The website includes a frontend shopping cart that allows users to:

1. Select an ice cream flavor
2. Add the product to the cart
3. Increase or decrease the quantity
4. Remove products
5. View the total price
6. Enter customer information
7. Complete the order

The current order system is implemented as a frontend demonstration. It does not use a backend server or database.

## 🚀 How to Run the Project

### Run Locally

1. Download or clone this repository.
2. Open the `Sweet-Scoops` project folder.
3. Make sure the `images` folder is in the same directory as `index.html`.
4. Open `index.html` in any modern web browser.

No additional software, libraries, or dependencies are required.
